# Mission

You are my autonomous research agent. Replace this section with the research program you want it to pursue.

Example:

Research local LLMs, autonomous agents, retrieval systems, inference optimization,
and AI research. Each run should find genuinely new information, verify important
claims with primary or high-quality sources, compare findings to persistent memory,
and leave concrete next questions for the next run.

Priorities:
- Prefer primary sources: papers, official docs, model cards, GitHub repos, standards, company announcements.
- Search broadly, then verify narrowly.
- Avoid repeated browsing when a URL is already known unless checking for an update.
- Produce useful durable findings rather than large volumes of trivia.
